Membangun Web Pencarian PDDIKTI Khusus UNSRAT

📅 Mei 2026

Proyek pengembangan Single Page Application (SPA) yang berfungsi sebagai portal pencarian profil Mahasiswa dan Dosen khusus Universitas Sam Ratulangi (UNSRAT). Dibangun menggunakan PHP sebagai Proxy API untuk mengatasi isu CORS, serta antarmuka modern dengan Tailwind CSS. Sistem ini dilengkapi fitur pintar seperti filter otomatis kampus, deteksi identitas dinamis (Mahasiswa/Dosen), ekstraksi tahun angkatan dari NIM, hingga algoritma ekstraksi data JSON mentah. Hasil akhirnya adalah sebuah Sistem Informasi Akademik mini yang efisien dan otomatis.
