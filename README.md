## 💡 Tentang Proyek Ini

Website portofolio ini dibangun menggunakan fondasi **HTML, CSS, dan JavaScript Vanilla** murni. Desain mengusung tema gelap (*dark mode*) bergaya *cyberpunk/futuristik* yang elegan. Dilengkapi dengan efek *Glassmorphism* premium, latar belakang gradasi yang bergerak (*animated gradient*), dan interaksi 3D, memberikan kesan modern, interaktif, dan profesional.

## ✨ Fitur Utama

- **UI/UX & Animasi Modern:** Menggunakan *animated background*, *shimmering text gradient*, dan efek kaca buram (*glassmorphism*) dengan *inner-glow* yang rapi.
- **Efek Interaktif 3D Tilt (Vanilla JS):** Kartu data diri dan *skills* dilengkapi dengan logika matematika JavaScript murni untuk menciptakan efek kemiringan (3D tilt) yang merespons secara mulus terhadap pergerakan kursor *mouse*.
- **Animasi Dinamis:** Terdapat efek mengetik otomatis (*typing animation*), kursor berkedip, *floating profile image*, dan animasi *scroll reveal* saat halaman digulir.
- **Responsif Sepenuhnya:** Layout otomatis menyesuaikan dari desktop hingga smartphone, dilengkapi dengan sistem *hamburger menu* pintar untuk tampilan *mobile*.
- **Integrasi Media Sosial & Kontak:** Halaman kontak tidak hanya menampilkan data diri akademik, tetapi juga integrasi tautan langsung ke media sosial profesional (Instagram, WhatsApp, LinkedIn) menggunakan ikon responsif.
- **Showcase Proyek (Blog):** Menampilkan minimal 3 artikel atau studi kasus proyek (misal: web pencarian PDDIKTI, prototipe IoT & AI, SaaS, dsb.).

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur web semantik modern.
- **CSS3**: *Custom Properties/Variables*, *Flexbox*, *CSS Grid*, *Keyframes Animations*, *Backdrop-filter*, serta transformasi 3D (`preserve-3d`, `rotateX/Y`).
- **JavaScript (Vanilla)**:  
  Untuk logika *menu toggle*, perhitungan matematika untuk efek interaktif 3D Tilt, animasi *scroll reveal* menggunakan *Intersection Observer*, dan algoritma *typing animation*.
- **Google Fonts**:  
  Tipografi modern menggunakan keluarga font 'Poppins'.
- **FontAwesome (CDN)**:  
  Digunakan secara ringan khusus untuk memuat ikon vektor (seperti ikon user, pendidikan, amplop, dan tautan).
